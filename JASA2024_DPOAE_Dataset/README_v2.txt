Distortion-Product Otoacoustic Emission and Audiometric Threshold Dataset

This dataset accompanies the 2024 JASA paper:
“Detection of Mild Sensory Hearing Loss Using a Joint Reflection–Distortion Otoacoustic Emission Profile”

Participant Groups

- NH: Participants with normal hearing (n = 117)
- HI: Participants with hearing impairment (n = 183)

File Organization

The dataset includes two Excel workbooks for each participant.

1. Detailed DPOAE Data

The [Subject ID]_Detailed_DPOAE_Data.xlsx workbook contains audiometric thresholds and detailed DPOAE measurements.

Audio sheet:

- Column 1: Frequency (kHz)
- Column 2: Air-conduction hearing threshold (dB HL)

DPOAE sheets:

The remaining sheets are labeled according to the L2 level (dB FPL). If a sheet is absent, that condition was not tested for the participant.

- Column 1: f2 frequency (kHz)
- Column 2: OAE level (dB EPL)
- Column 3: Noise level (dB EPL)
- Column 4: Phase (cycles)
- Column 5: Delay (ms)
- Column 6: SNR (dB)

Detailed DPOAE measurements were processed using an artifact-rejection routine.

2. Band-Averaged DPOAE Data

The [Subject ID]_BandAveraged_DPOAE_Data.xlsx workbook contains half-octave-band-averaged DPOAE measurements. Sheets are labeled according to the L2 level (dB FPL). If a sheet is absent, that condition was not tested for the participant.

- Column 1: f2 frequency (kHz)
- Column 2: OAE level (dB EPL)
- Column 3: Noise level (dB EPL)
- Column 4: SNR (dB)

Band-averaged measurements were processed using a noise-based cleaning routine.
